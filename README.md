# UnipusHelper.NET

登录遇到 1506（需要图片或滑块验证码）时，程序会打开浏览器。请在 5 分钟内手动完成验证，程序会继续登录；滑块无法加载时可选择“图片验证码”。浏览器未自动打开时，可手动访问终端显示的本地地址。取消添加任务会停止等待验证，账号和密码不会传入此页面。

U校园AI版自动答题工具（新视野大学英语）
